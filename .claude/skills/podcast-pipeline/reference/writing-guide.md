# 写作原则（非虚构写作标准）

> Step 3 提炼核心文本 + Step 4 生成社交文案时，必须严格遵循。

## 核心文本写作原则（Step 3）

核心理念：替读者做减法，用叙事而非罗列传递信息。

- **一条线索贯穿**：找到这期播客的核心张力或核心问题，所有段落围绕它展开。不是"嘉宾聊了 A、B、C、D"的要点罗列
- **叙事推进靠因果和转折**：每一段存在的理由是它和上一段的关系——"她从X讲起，但话锋一转到Y，因为……"，而不是"她还说了Z"
- **具体细节优先**：一个好的场景胜过三句概括。保留嘉宾的具体类比、案例、数字，让读者自己得出结论
- **保留口语叙事的现场感**：播客的魅力是对话中的碰撞、犹豫、举例。转述应保留这种质感，不要洗成书面语
- **来源精确**：谁说的就是谁说的，不模糊归因，不把两个人的话揉成一段通论
- **语言平实**：不造作，不升华，不抒情。像一个见过世面的人在平静地讲事情

❌ **绝对禁止**：
- LLM 总结体："核心判断很直接"、"换句话说"、"综上所述"、"值得关注的是"、"不得不说"
- 虚假升华："这让我重新思考了……"、"未来属于那些……的人"
- 并列堆砌：段落之间只是 "另外"、"此外"、"还有一个" 的罗列关系
- 对称结构：每段都是"某某说了什么 → 我的感受"的重复模式

## 社交文案写作原则（Step 4）

**核心定位**：用最少的字让人知道这期讲了什么值得关注的事。像在跟一个聪明的朋友转述，不煽情、不升华、不总结。

**开头**：
- 第一句点明来源：哪个播客、谁、聊了什么
- 直接切入最有信息量的细节或判断，不要从抽象概念起笔
- 例："Latent Space 这期请了 NVIDIA 的 Kyle Kranen，把推理系统 Dynamo 的架构掰开讲了一遍。最关键的一刀：把 prefill 和 decode 拆到不同机器上跑。"

**写作要求**：
- 平实、精确、不造作
- 态度来自选择——你选了哪些内容来写、省略了哪些，本身就是判断。不需要加"我觉得这很重要"来表态
- 不虚构个人经历来制造亲近感
- 不用"我认同"、"我记下来了"、"这期让我印象最深的是"来伪装立场
- 段落之间有叙事推进，不是换个角度重复同一个意思

❌ **禁止**：
- 模板化开头："我听完最大的感受是"、"这期让我印象最深的是"
- 虚构场景："我一边听一边想到自己最近……"
- 口号式结尾："谁能在XX里守住XX，谁才跟得上XX"
- 任何形式的"读后感"语气
