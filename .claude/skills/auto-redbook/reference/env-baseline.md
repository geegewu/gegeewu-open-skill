# XHS MCP 环境变量基线

读取：`~/.env`

建议基线：

```bash
USE_XHS_MCP=1
XHS_MCP_LOCK_MAX_WAIT=180
XHS_MCP_LOCK_POLL_INTERVAL=3
XHS_MCP_STALE_LOCK_MINUTES=15
XHS_MCP_CONNECT_TIMEOUT=1
XHS_MCP_START_WAIT_SECONDS=2
XHS_MCP_HTTP_TIMEOUT=90
XHS_MCP_ME_TIMEOUT=8
XHS_MCP_MAX_ATTEMPTS=2
XHS_MCP_RETRY_WAIT_SECONDS=2
XHS_MCP_NOTE_ID_RECOVERY_MAX_WAIT=120
XHS_MCP_NOTE_ID_RECOVERY_INTERVAL=3
XHS_MCP_NOTE_ID_RECOVERY_REQUEST_TIMEOUT=12
XHS_MCP_CONTENT_MAX_LENGTH=1000
XHS_PUBLISH_SOFT_CONTENT_LIMIT=950
XHS_MCP_FALLBACK_ON_FAIL=0
```

> 脚本通过 `get_env_int()` 读取这些值，均有代码内默认值。此处仅为参考基线。
